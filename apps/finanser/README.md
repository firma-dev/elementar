# финансер

Первый выпускаемый корпус Элементара. Выписка банка раскладывается по категориям
прямо в браузере: ни сервера, ни аккаунтов, ни одного внешнего запроса.

Отдельное приложение, а не дверь в `apps/web` — решение **Д-012**. Один шрифт и
суммы без знака рубля — **Д-014** (отменяет Д-013). Планы денег вместо флага
«исключить переводы» — **Д-015**. Категория ставится получателю — **Д-016**.
Свой токен-слой вместо палитры `@elementar/ui` — **Д-017**. Вид операции выше
словаря — **Д-018**. Год и месяц не показываются одновременно — **Д-019**. Маркетплейсы и алкоголь
отдельными категориями, и честный разговор про «Прочее» — **Д-020**. Тесты
вёрстки — **Д-021**. Перенос правок и склейка счетов — **Д-022**. Период,
поиск, словарь на экране — **Д-023**.

Вид перенесён с прототипа дизайн-сессии «Финансер v0.dc.html»: светлая бумага,
один OCR на весь текст, рамки вместо заливок, жёсткие тени со смещением, нулевые
радиусы. Расхождения с прототипом названы в Д-017 — их два, и оба сознательные.

## Что делает v0

- читает выгрузку Т-Банка в CSV (windows-1251 и UTF-8, `;` и `,`, кавычки, валютные операции);
- раскладывает по категориям: рука на операции → рука на получателе → вид операции → словарь → MCC → столбец банка;
- отделяет траты от движений денег: снятие наличных и переводы не раздувают годовую сумму;
- показывает траты по месяцам и долю каждой категории; по нажатию на месяц — его итоги;
- собирает неопознанных получателей в строки, где категория ставится одним движением;
- по нажатию считает сводку: топ, дорогой и дешёвый месяц, динамика, аномалии, регулярные платежи;
- выгружает разобранное в JSON;
- умеет несколько выписок сразу: дебетовая и кредитная складываются в одну картину;
- возит правки в JSON и читает их обратно — разметка переживает смену браузера;
- показывает словарь, по которому раскладывает, и даёт снять свои правки;
- работает офлайн и открывается по прямой ссылке.

## Работа

```bash
pnpm --filter @elementar/finanser dev        # http://localhost:5174
pnpm --filter @elementar/finanser build      # сборка + гейт герметичности
pnpm --filter @elementar/finanser preview    # посмотреть собранное
pnpm vitest run apps/finanser                # тесты
```

## Гейт герметичности

`pnpm --filter @elementar/finanser run check:hermetic` грепает собранный бандл и
падает на любом чужом происхождении. Обещание «ни один байт не уходит с
устройства» проверяется отсутствием адресов в ассетах, а не рассуждением о том,
что код не вызывается. Единственное исключение — пространства имён XML
(`http://www.w3.org/…`): это идентификаторы для `createElementNS`, браузер по ним
никуда не ходит.

Гейт вшит в `build`: красная герметичность = красная сборка.

## Выкатка

`dist/` кладётся на статик-хостинг как есть. Собрано с `base: './'` — все адреса
относительные, поэтому приложение работает и в корне сайта, и по пути
`/финансер/`, без пересборки.

**Адрес обязан кончаться слешем.** `…/финансер/` — да, `…/финансер` — нет: без
слеша браузер считает последний сегмент именем файла, и `sw.js`, манифест и
шрифты уезжают на уровень выше. На хостинге нужен редирект `…/финансер` →
`…/финансер/`.

**Заголовки.** Статик-хранилище своих заголовков не даёт, поэтому политика живёт
в самой странице настолько, насколько это возможно. Если хостинг умеет заголовки,
поставить руками:

```
Content-Security-Policy: default-src 'self'; base-uri 'none'; object-src 'none'; frame-ancestors 'none'; form-action 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self'; connect-src 'none'; manifest-src 'self'; worker-src 'self'
Referrer-Policy: no-referrer
X-Content-Type-Options: nosniff
Cross-Origin-Opener-Policy: same-origin
Permissions-Policy: geolocation=(), camera=(), microphone=(), interest-cohort=()
```

`connect-src 'none'` здесь не преувеличение: финансер не делает ни одного
запроса из кода. Сервис-воркер берёт своё из кэша и из того же происхождения.

`/assets/*` — `Cache-Control: public, max-age=31536000, immutable` (имена с хешем).
`index.html` и `sw.js` — `no-cache`.

**Открыто по выкатке:**

- **Заголовки на `.js` и `.css` ставит nginx, а не наш `.htaccess`.** Расширения
  из `nginx_static_ext` отдаются фронтендом мимо Apache, и вместо `immutable`
  там приходит `max-age=3888000`. На ассетах с хешем в имени это безразлично,
  на `sw.js` — нет, но браузеры и так ревалидируют скрипт воркера не реже раза
  в сутки. Чистое решение — убрать `js,css` из `nginx_static_ext` у сайта.
- Идентификация домена через Госуслуги не пройдена; с 1 сентября 2026 без неё
  блокируются продление и управление делегированием.
- Хостинг оплачен до 07.09.2026, автопродление включено, но карта не привязана.

## Обновление версий

Сервис-воркер **не** делает `skipWaiting` и не захватывает уже открытые вкладки.
Это не осторожность, а исправление гонки: старая вкладка держит старый
`index.html` с именами ассетов по старому хешу, и если новый воркер снесёт
прежний кэш под ней, эти ассеты исчезнут — хостинг ответит на них страницей
(SPA-фолбэк, 200 `text/html`), модуль не загрузится, человек увидит белый экран.
Новая версия встаёт при следующем холодном запуске.

Плашки «доступна новая версия» (`ARCHITECTURE.md` §13.6) в v0 нет — это долг,
а не решение.

## Долги v0

- **Канон и корпус расходятся по шрифту.** `elementar-canon.md:86-87` называет два
  шрифта, финансер по Д-014 набран одним. Запись Д-014 действует только на корпус;
  канон правит человек, и до его правки расхождение остаётся.
- MCC из выписки читается, но в категоризации не используется — только описание,
  получатель и столбец банка.
- Вклады и инвестиции не отделены от переводов внутри плана `move`: в выписке,
  на которой это проверялось, их нет. Нужен признак — категория или MCC.
- **Офлайн ни разу не проверен вживую.** Воркер написан и лежит на сервере, но
  встроенная панель браузера не даёт регистрировать сервис-воркеры, а на боевом
  адресе HTTPS появился только сегодня. Проверить — на живой ссылке.
- Тёмная сторона взята из токенов дизайнера, но прототип её не показывал:
  нужен его глаз (Д-023).
- Словарь правил правится только в коде; экрана для него нет.
- Счётной сводки и выгрузки JSON в прототипе нет; оставлены по ТЗ §2 п.5–6 и
  одеты в его язык. Если объём v0 сокращается — это решение, а не умолчание.
- «Прочее» на настоящей годовой выписке — 23% трат (было 51%). Это потолок
  словаря: хвост из полутора сотен разовых заведений и ИП неопознаваем в
  принципе. Ниже он опускается либо полной выгрузкой Т-Банка с MCC, либо рукой
  в «Разборе непонятного» — приложение ведёт к обоим (Д-020).
