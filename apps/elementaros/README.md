# элементар ос

Лендинг-манифест: вертикальная лента из двенадцати экранов, один экран — один
тезис. Домен `elementaros`. Материал внутренний, для показа соучастникам, —
поэтому в нём нет ни формы, ни кнопки действия, ни призыва, а поисковики
отключены мета-тегом `robots`.

```
pnpm dev:os      # разработка, http://localhost:5177
pnpm build:os    # сборка в apps/elementaros/dist
```

## Что где

| Файл              | Что в нём                                                    |
| ----------------- | ------------------------------------------------------------ |
| `src/app.tsx`     | все двенадцать экранов и все тексты, дословно                |
| `src/Screen.tsx`  | оболочка экрана: метка, столбец, подпись внизу               |
| `src/Window.tsx`  | прямоугольное окно с титлбаром — опорный приём айдентики     |
| `src/Logo.tsx`    | знак Элементара разметкой, повторяет `elementar.svg` в корне |
| `src/Rail.tsx`    | рейка номеров справа, список читается из разметки            |
| `src/landing.css` | стили; цвета и отступы — только токены `@elementar/ui`       |

## Правила, за которыми следят тесты

`test/landing.test.ts` проверяет по исходнику: тезисы стоят дословно, экранов
двенадцать и они пронумерованы подряд, в стилях нет ни одного цвета мимо
токенов и ни одного пикселя, кроме волосяной линии.

Тексты выверены. Правка формулировки — отдельное решение человека: тест на неё
падает намеренно.
