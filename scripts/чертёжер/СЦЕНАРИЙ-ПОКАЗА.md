# Сценарий показа чертёжера ИТ-отделу, 5 минут

Владелец показывает на своём Маке. Файлы настоящие (комплект 1042, К2) — владелец
разрешил показывать их вместе с именами (06.10.2026). Все команды ниже проверены 06.10.2026; страница — по новой вёрстке, проверена в Chromium и WebKit на 1440×900 и 1000×650.

Обозначения: **[Терминал]** — Terminal.app; **[Браузер]** — окно, которое откроется само.
Рабочая папка до слияния ветки в main: `~/Documents/elementar-chertezher/scripts/чертёжер`.
После слияния: `~/Documents/elementar/scripts/чертёжер`. Ниже — первая.

## До показа (утром, 3 минуты, не при ИТ)

**[Терминал], любая папка**

    cd ~/Documents/elementar-chertezher/scripts/чертёжер
    .venv/bin/python check.py                      # ждём: «Чертёжер в порядке.»
    .venv/bin/python демо/проверка-демо.py         # ждём: «Демо в порядке: 3 чертежа…»
    dwg2dxf --version                              # ждём: dwg2dxf 0.14
    lsof -nP -iTCP:8765 -sTCP:LISTEN               # ждём: пусто. Если строка есть — порт занят: Ctrl+C в окне,
                                                   # где чертёжер уже запущен, либо запускайте с --port 8766

Если `.venv` нет: `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt` (интернет нужен
один раз, 11 секунд).

Файлы для показа лежат в Загрузках (Finder → Загрузки):
`1042-1-Р-1042-АР2.5-К2_1.dwg` (0,7 МБ), `1042-АР4.1-К2_л.1.dwg` (1,5 МБ), `чертёжер-эталоны/К2_2.dxf` (7 МБ).

## По минутам

**0:00–0:30. Что это.** [Терминал], папка `scripts/чертёжер`:

    .venv/bin/python app.py

Откроется [Браузер] с адресом `http://127.0.0.1:8765`. Сказать: «Берёт чертёж из AutoCAD или
Revit, выдаёт чистый SVG: геометрия как есть, без текста, размеров, осей и штампа. Работает на
этом компьютере, адрес 127.0.0.1 — только он сам».
Показать: страница в один экран — слева шаги «1 Чертёж», «2 Стиль» (образец палитры, под
ним свёрнутые «Цифры на чертеже»), кнопка «Собрать SVG»; справа большая зона «Перетащите
DWG или DXF». Светлая; тёмная — кнопкой «Тёмная тема» справа вверху (если спросят).

**0:30–1:15. Только этот компьютер.** [Терминал], **второе окно или вкладка** (⌘T), любая папка:

    lsof -nP -iTCP:8765 -sTCP:LISTEN
    curl -s -o /dev/null -w "%{http_code}\n" -H "Host: evil.example:8765" http://127.0.0.1:8765/

Ждём: в первой команде адрес `127.0.0.1:8765 (LISTEN)`, не `*:8765`; во второй — `403`.
Сказать: «Слушает только свой адрес; запрос с чужим именем хоста отвергается».

**1:15–2:15. Настоящий DWG.** [Браузер]: перетащить в окно `1042-1-Р-1042-АР2.5-К2_1.dwg` из
Finder (Загрузки) → слева «Собрать SVG». Справа идут стадии «Читаю DWG → Убираю оформление →
Строю пол → Рисую», ~2 с. Показать превью на всю сцену и итог слева: убрано объектов 2 271,
помещений залито 77 из 77, номеров помещений 77, цифр перенесено 209 (скрыто наложением 1),
лист 437 × 570 мм, 1:100; «На листе 2 чертежа — собран самый крупный». Сказать: «DWG сначала
превращает отдельная программа libredwg, дальше наш код. Каждый объект учтён: нарисован или
назван, почему убран». Нажать «Скачать SVG» — файл `1042-1-Р-1042-АР2.5-К2_1.svg` в Загрузках.
Номера помещений — шрифтом ITC Officina, в SVG они кривые, шрифта в файле нет.

**2:15–3:30. «Проверка».** [Браузер]: перетащить `1042-АР4.1-К2_л.1.dwg` → «Собрать заново»
(~4 с) → вкладка «Проверка: DWG и SVG». Над листом подписи: серое — **DWG, исходник**, чёрное —
**SVG, результат**, красное — только в DWG (убрано), синее — только в SVG (добавлено). Строка
зелёным: «Геометрия совпала полностью, убрано только оформление: 6 263 объекта» и разбивка —
размеры, текст и марки, оси, штриховки, облака правок. Нажать **пробел** несколько раз: на
одном месте листа сменяются DWG и SVG (подпись в углу говорит, что на экране). Кнопка
**«Рядом»** — две картинки бок о бок с общим масштабом; **«Оба»** — обратно. Покрутить колесо,
потянуть мышью. «Заливка результата» — результат в цветах стиля поверх исходника. Сказать:
«Видно, что именно выброшено, а что оставлено; ничего не дорисовано, кроме пола и цифр —
пол вычисляется и приблизителен».

**3:30–4:15. Безопасность и лицензии.** Открыть `ДЛЯ-ИТ.md` (в [Терминал]: `open ДЛЯ-ИТ.md`
или в редакторе). Пройти по разделам «Что уходит наружу: ничего» и «Зависимости и лицензии».
Главное: нет сетевых библиотек в коде; временный каталог удаляется; libredwg (GPL) — отдельная
программа, не вшита; Python, ezdxf (MIT), shapely (BSD).

**4:15–5:00. Ограничения и дальше.** По разделам «Ограничения» и «Что дальше» того же файла:
бета; нет входа по паролю на localhost; заливка пола приблизительна; профили раскладки.

Завершить: [Терминал], окно с приложением — Ctrl+C. Строка «остановлен».

## Если что-то не запустилось

| Что случилось | Запасной ход |
|---|---|
| «порт 8765 не открылся» | `.venv/bin/python app.py --port 8766`, открыть `http://127.0.0.1:8766` |
| Браузер не открылся | скопировать адрес из строки «чертёжер: http://127.0.0.1:…» в браузер |
| `no such file .venv/bin/python` | `python3 -m venv .venv && .venv/bin/pip install -r requirements.txt` |
| DWG не читается («dwg2dxf не смог…») | перетащить DXF: `чертёжер-эталоны/К2_2.dxf` (DXF работает без libredwg) |
| В «Подробностях» строка «ВНИМАНИЕ: шрифт стиля не найден» | на этой машине нет ITC Officina (`~/Library/Fonts/ITC Officina Sans_Book.otf`): цифры другим шрифтом, `check.py` и `демо/проверка-демо.py` покраснеют. Показ не срывает |
| Предупреждение про версию dwg2dxf | не ошибка; сказать «проверялось на 0.14» |
| Стадии идут дольше 10 секунд | файл тяжёлый; дождаться (последняя стадия «Рисую» закрывается только готовым результатом) или взять `К2_1.dwg` (2 секунды) |
| Справа «Не получилось» | там написано, что случилось и что сделать; кнопка «Выбрать другой файл» |
| В «Проверке» нет красного и синего | включить «Подсветить отличия» и выбрать «Оба»; подсветка появляется через долю секунды после остановки зума |
| Приложение не стартует совсем | демо без приложения: SVG из `демо/эталон-*.svg` открыть двойным щелчком в Finder (папка `scripts/чертёжер/демо`), показать `ДЛЯ-ИТ.md` |
| Спросили то, чего нет в `ДЛЯ-ИТ.md` | «ответим письменно» |

Своих демо-чертежей (без клиентских имён) три штуки: `scripts/чертёжер/демо/план-комнаты.dxf`,
`деталь-узла.dxf`, `слои-штриховка.dxf`; если их нет — `.venv/bin/python демо/сделать-демо.py`.
