# решение 001 · инфраструктура под российскую аудиторию

Статус: принято, 17 августа 2026.
Отменяет: раздел «Стек» в `elementar-canon.md` в части инфраструктуры.

---

## Контекст

Сто процентов пользователей Элементара находятся в России и пользуются продуктами без VPN. Это не предположение, а исходное условие: первые пользователи — автор, его партнёр, отец, друзья.

Cloudflare, выбранный ранее, из России работает нестабильно. Механика проблемы:

- российские операторы блокируют TLS-соединения с расширением ECH, включённым у Cloudflare по умолчанию
- блокировка точечная, через DPI: хендшейк подвисает на 5–10 секунд или падает
- пользователь не видит «сайт заблокирован» — он видит медленную загрузку и закрывает вкладку
- Cloudflare держит тысячи сайтов на общих IP: если рядом оказался заблокированный ресурс, оператор может закрыть адрес целиком

Отключение ECH лечит симптом, но проблема общих IP от нас не зависит.

Для глобального сервиса, где Россия — десять процентов трафика, это терпимо. Для Элементара это отказ продукта у всех пользователей.

## Решение

**Инфраструктура — российская.** Cloudflare исключается из стека полностью.

Замена по компонентам:

| Было | Стало |
|---|---|
| Cloudflare Pages | Yandex Object Storage (хостинг статики) или Timeweb Cloud |
| Cloudflare Workers | Yandex Cloud Functions |
| D1 | YDB или PostgreSQL у российского провайдера, когда понадобится |
| R2 | Yandex Object Storage |
| Durable Objects | исключается, см. следствие ниже |

**Что не меняется:** TypeScript, pnpm-монорепо, Vite, Preact. Клиентская часть от решения не зависит.

**Домен:** `.ru` через российского регистратора, оплата рублями.

## Следствие: парный планер без реального времени

Durable Objects были главным аргументом в пользу Cloudflare — они давали realtime-координацию на документ. Аргумент снят вместе с провайдером.

Пересмотр требования: мгновенная синхронизация нужна для совместного редактирования текста, а не для отметки галочки в списке дел. Синхронизация с интервалом в несколько секунд и разрешением конфликтов по времени последнего изменения даёт почти то же ощущение на порядок дешевле.

**Парный планер проектируется без реального времени.** Отдельный WebSocket-сервер на арендованной машине рассматривается только если периодическая синхронизация окажется на практике недостаточной.

## Следствие: модель тоже российская

Прокси к модели живёт в Yandex Cloud Functions, модель вызывается через GigaChat или YandexGPT. Оплата рублями, серверы в РФ, доступ без VPN.

Для распознавания скриншотов в финансере: GigaChat (мультимодальный, отдаёт готовый JSON) как основной путь, Yandex Vision OCR как запасной.

Побочная выгода: для приложения, обрабатывающего банковские скриншоты, российская обработка данных — аргумент не только технический.

## Цена решения

Сейчас — нулевая. Финансеру первой версии бэкенд не нужен вообще: статика плюс одна прокси-функция. Серверного кода на Cloudflare ещё не написано.

Через два месяца, после парного планера на Durable Objects, — недели переписывания. Поэтому решение принимается до первой строчки серверного кода.

## Проверка

Перед деплоем финансера — открыть его с мобильного интернета МТС и Ростелекома, не с домашнего вайфая. Разные операторы ведут себя по-разному; своя проверка надёжнее обзоров.
